# Exercice 01 : Architecture Réseau Packet Tracer

## Description
Ce projet présente la configuration d'une topologie réseau comprenant un routeur et trois switchs....

## Fichiers inclus
- `Exercice 01 Packet Tracer.pkt` : Le fichier source de la topologie.
- `Config Routeur.txt` : Configuration complète du routeur.
- `Config SwitchX.txt` : Configurations respectives des switchs 0, 1 et 2.

## Processus de réalisation
1. **Adressage IP** : Attribution des adresses sur les interfaces G0/0, G0/1...
2. **VLANs** : Création et assignation des ports sur les switchs.
3. **Sécurité** : Configuration des mots de passe (enable secret) et accès SSH/Telnet.
4. **Vérification** : Tests de connectivité (Ping) entre tous les hôtes.
